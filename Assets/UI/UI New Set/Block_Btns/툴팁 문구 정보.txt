세방고딕 폰트 사용
글씨 색 #1C1C1C

정수 :: 특정한 값의 정수를 입력합니다.
바이러스:: 특정한 종류의 바이러스를 입력합니다.

Start :: 이 블록으로 코드를 시작합니다.
멍멍이 :: 이 블록으로 코드를 마칩니다. 백신 멍멍이가 태어납니다.
특공대(포병) :: 이 블록으로 코드를 마칩니다. 백신 특공대가 태어납니다.

이동한다 :: 백신이 '정수'만큼 데이터 로드를 이동합니다.
공격한다 :: 백신이 무기를 휘둘러 공격합니다.

IF 보다 :: 백신이 '보는 것'을 판단합니다. 'True'와 'False'를 반환합니다.
While :: True일때 반복합니다. 끝없이...

새 함수 :: 새로운 함수를 만듭니다.

함수 1 :: 함수 1번 세트입니다
